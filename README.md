AWS-Custom-VPC-Configuration

This lab walks through the foundational process of creating a Custom Virtual Private Cloud (VPC) on AWS. You will learn how to define a 
private network space, understand CIDR block sizing, and manage IP address scalability by expanding the range of available hosts.

Architecture Components

**VPC (Virtual Private Cloud): A logically isolated section of the AWS Cloud.

**IPv4 CIDR Blocks: The IP address ranges that define the size of your network.

**Control Plane: The AWS Management Console used to provision networking resources.

Lab Goals

**Provision a new custom VPC.

**Define initial network boundaries using CIDR notation (e.g., /16 vs /24).

**Modify an existing VPC to increase host capacity by adding secondary CIDR blocks.
